## Groma

[Groma](https://github.com/MrLesk/groma.md) is an optional tool for exploring
how this repository's main parts fit together. The architecture map lives in
[`.groma/`](.groma/). With Groma installed, run `groma web` from the repository
root to view the map in a browser.

Before using Groma, check whether it is available with `command -v groma`.
If it is not available and Groma is relevant to the work, ask the user whether
they would like it installed. Do not install it without approval. If they
decline, continue without Groma; normal repository work does not require it.

If Groma is available, run `groma agent-instructions` and read the guide it
names before scanning, inspecting, or curating the map, or changing files for
a Backlog task. If Groma reports a first scan, ask the user before curating it.
Use the Groma CLI rather than editing Groma-owned architecture files directly.
