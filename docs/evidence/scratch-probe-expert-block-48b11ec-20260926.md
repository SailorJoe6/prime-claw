## Finding: retained mode exceeds macOS Unix socket address capacity

`scripts/run-prime-agent-probe.sh:15–16` creates a 33-byte basename under the inherited (potentially long) `TMPDIR` and canonicalizes it. Retained mode then uses `<root>/tmp` without budgeting native socket paths (`:32–42`). Prime Agent v0.9.6 constructs `tmpdir()/prime-agent-<uid>/daemon.sock` (`packages/coding-agent/src/modes/daemon/daemon-socket.ts:70–75,279–282`) and a longer `worker-<12-hex-key>-<12-character-id>.sock` in the **same default socket directory** (`daemon-supervisor.ts:692–693,708–713`). A custom supervisor `--daemon-socket` does not shorten the worker path. The installed macOS SDK has `sun_path[104]` in `sys/un.h:76–79`; even the full 104 bytes leaves no terminator budget.

The independent review and owner static calculation agree: on this host, the current inherited temp parent produces a 124-byte supervisor path and 150-byte worker path. Using `/tmp` alone canonicalizes to `/private/tmp`; with the existing long prefix the paths would be 80 and **106** bytes. No socket was opened. `tests/test_prime_agent_probe_isolation.py:57–110` tests private environment/directory behavior, not socket path bytes, so four passing tests did not expose this defect.

**Violated invariant and impact:** a scratch daemon needs a private, usable socket namespace with stable address identity. These absolute paths cannot fit the macOS address structure, so startup must fail or truncate. A supervisor may start before worker socket creation fails; that is an uncertain partial-start case for the later cleanup driver. This is **not** evidence of cross-root leakage.

**Root-cause seam:** the wrapper treats a valid filesystem directory as a valid AF_UNIX address root and does not budget the canonical parent and longest upstream worker filename.

**Recommended repair:** use a short, private, canonical root for retained daemon probes; before admitting the command, validate the encoded byte budget of both the supervisor and maximum worker socket paths. Fail closed when the platform limit cannot be met. Keep ordinary short-probe behavior unchanged. Do not fix only `--daemon-socket`, use the user's shared socket directory, depend on `/tmp` symlink spelling, discard failed-start evidence, alter Prime Agent core, or launch a native fixture before the separate teardown gate.

**Acceptance tests:** positive tests prove canonical co-rooted private `HOME`/config/sessions/`TMPDIR` and fitting supervisor plus maximum worker path bytes; negative tests cover long and multibyte inherited `TMPDIR` and `/tmp` → `/private/tmp`, requiring safe short placement or pre-command rejection; failure tests cover rejection and command-not-found/nonzero retention/reporting; replay tests prove two distinct fitting namespaces and unchanged ordinary cleanup/exit status. Temp placement can change state-root shutdown matching, artifact discovery, and default cleanup assumptions. Repair wrapper, tests, and documentation together.
