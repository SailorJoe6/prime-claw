Use only for this Conversation's active Episode: select the `.prime-claw/ownership.json` entry keyed by its exact `ownerSessionId`, accepting direct migration records. Version 1 selects retained folder oversight; version 2 selects task-native oversight. Tags never override it.

Independent mode uses ignored nested clones; task commits/pushes never enter the code DAG.

Use exact operator-authorized version-1 recovery, legacy `handoff_spec_episode`/`finalize_spec_episode`, and no task-native authority.

Preserve resources; Beads requires historical-head ancestry/clean code. An exact same-binding replay is the only idempotent replay; plan deletion remains a separate reviewed step.

Review one reported slice at a time. Check ownership/code/tests/docs/authority. For independent Backlog, compare persisted/current complete native task evidence/revision/publication. For Beads, compare the persisted raw task and revision with the synchronized current raw task, publication ref, candidate code base/head. An unrelated-task revision descendant alone is compatible. Use bounded LLM judgment to decide whether it is a compatible in-scope clarification or living-plan update; escalate a genuine semantic conflict, authority change, scope expansion, or product decision. Raw inequality grants no approval. Never replace this judgment with a classifier or equality gate. Apply before handoff, blocker, terminal work, and cleanup; mutate only as authorized.

A report, findings, and Review conclusions are evidence, not approval. Choose:

- **Accept and advance** when evidence supports scope. For Beads, `handoff_task_episode` supplies exact previous/current native context to the existing Episode LLM. Compatible owner-authored, outside same-task, and unrelated descendant changes continue.

- **Pause** without a product decision.
- **Consult the operator** for scope, product, merge, abandonment, conflicting evidence, blockers, or cleanup outside task-native authority.
